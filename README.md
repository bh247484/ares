## What's this fork about?

I forked the ares codebase for an experimental project which integrates (i.e. hacks) custom game audio middleware into emulated console hardware architecture(s). The idea is to be able to design your own sounds and write your own music for classic games and then trigger them within an emulator in real time. One solution for all the games in that console's catalog. No need to reverse engineer or manipulate any game's source code. So far I have this working for ares' SNES emulator.

Check out this PR for see more details and to visualize the code diff: [`https://github.com/bh247484/ares/pull/1`](https://github.com/bh247484/ares/pull/1)
